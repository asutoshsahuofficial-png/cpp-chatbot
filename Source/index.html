About This Project

Chatbot Assistant is an academic software project created by BCA 2nd Semester students of Creative Techno College (CTC), Angul (affiliated with Utkal University). Built as an intelligent campus companion, it pairs a native C++17 server with cloud AI from the Groq API. With an integrated Retrieval-Augmented Generation (RAG) knowledge base trained directly on the official college website (creativecollege.in), it answers student inquiries about admissions, courses, fees, syllabus, and hostel life instantly—online or offline.

Native C++17 Engine

Custom C++17 server (chatbot_updated.exe) utilizing cpp-httplib with a 64-worker thread pool. Stores chat history locally, extracts text from Word (.docx) and text files, and answers queries instantly with zero external dependencies.

College Website RAG Engine

Grounds the AI with verified information from creativecollege.in (BCA, BBA, B.Sc, MCA, MBA courses, admissions, fees, hostels, and campus placements). Falls back to smart keyword matching when offline.

Cloud Generative AI

Connects to ultra-fast Groq cloud AI models using libcurl for open-ended questions. Feeds relevant college notes into prompts and supports image inspection with advanced vision models.

Technology Stack

Backend Engine: C++17 (MSVC / MinGW UCRT64)
HTTP Server: cpp-httplib v0.15 (ThreadPool: 64)
Serialization: nlohmann/json v3.11
Network Client: libcurl (TLS & SSL Verified)
Frontend Stack: HTML5, Responsive CSS3, Modern ES6 JS

Capabilities & Formats

Knowledge Source: creativecollege.in (265+ Verified FAQs)
Document Formats: .txt, .docx (Word documents & text notes)
Image Formats: .png, .jpg, .jpeg, .webp, .gif, .bmp
Chat History: Local JSON Filesystem
Admin Security: Password Login + Session Tokens
